# Hi, I'm Lucas 👋

Software developer in Melbourne. I build AI developer tools and ship small products end to end.

## What I'm building

- **[goldfish](https://github.com/lucasjamesss/goldfish)**: unified memory MCP server for AI coding agents. Cited transcript search, session context and curated notes in one server.
- **[spread-your-claudes](https://github.com/lucasjamesss/spread-your-claudes)**: offloads your coding agent's big-context reads to other AI CLIs (Gemini, Cursor, Codex) so its context window goes to deciding, not carrying the haystack.
- **[Turnitoff](https://github.com/lucasjamesss/Turnitoff)**: makes Claude and ChatGPT write like a person instead of an AI. Writing rule, checker, MCP server and Claude Code hook.
- **[Pijnhol](https://pijnhol.com)**: web app and marketing site, live in production.
